# Система учёта заказов

Учебное веб-приложение для работы заказчиков и исполнителей.

## Роли

- Заказчик создаёт и контролирует свои заказы.
- Исполнитель принимает заказы и меняет их статус.

## Лабораторные работы

1. Визуальный дизайн основных экранов.
2. Пользовательский интерфейс с тестовыми данными.
3. REST API и база данных.

Требования проекта находятся в каталоге `docs`, макеты первой лабораторной —
в каталоге `design`.

## Запуск второй лабораторной

```bash
npm install
npm start
```

После запуска приложение доступно по адресу `http://localhost:4200`.

Демонстрационные пользователи:

| Роль | Email | Пароль |
| --- | --- | --- |
| Заказчик | `customer@mail.ru` | `123456` |
| Исполнитель | `executor@mail.ru` | `123456` |

Во второй лабораторной сервер отсутствует. Пользователи и заказы хранятся в
памяти приложения и после обновления страницы возвращаются к исходным данным.

## Запуск третьей лабораторной

Сначала запустить API:

```bash
npm install --prefix backend
npm run backend:start
```

Затем во втором терминале запустить интерфейс:

```bash
npm install
npm start
```

Тесты бэкенда запускаются командой `npm run backend:test`.
